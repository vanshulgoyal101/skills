# Repository Intake Checklist

- [ ] Read `AGENTS.md`, `CLAUDE.md`, and repository-local instructions.
- [ ] Identify package manager, build command, test command, lint/typecheck command, and deploy command.
- [ ] Inspect existing test and CI conventions before proposing new gates.
- [ ] Choose a concrete bug, behavior, or verified constraint as the anchor.
- [ ] Reproduce it with the cheapest discriminating check.
- [ ] Record evidence without copying secrets, private data, or proprietary source.
- [ ] Extract the portable invariant into a skill.
- [ ] Record the concrete failure and fix in an incident.
- [ ] Add a regression/checklist entry only if the lesson generalizes.
- [ ] Update `SOURCES.md` and `CATALOG.md`.
- [ ] Run the skills repository link/structure validation.
