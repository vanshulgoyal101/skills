# Engineering Skills Repository

This repository stores reusable engineering knowledge extracted from real failures and verified fixes.

## Rules

- Add a skill only after the underlying behavior has been verified in code, a test, a live system, or a reproducible experiment.
- Prefer root causes and discriminating checks over generic advice.
- Every incident should name the trigger sequence, impact, evidence, fix, regression test, and residual risk.
- Keep skills repo-agnostic. Put repository-specific paths and commands in examples or incident records.
- Update `CATALOG.md` whenever a skill, checklist, template, or incident is added.
- Do not store secrets, production tokens, customer data, or copied proprietary source code here.
